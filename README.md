# 决斗者记录本 (精简版) - ygoRecord

这是一个基于 **uni-app + Vue 3** 开发的纯本地游戏王 (YGO) 战绩记录工具。由微信小程序「游戏王战绩记录工具」重构而来，专注于安卓端的本地化存储与流畅体验。

## 🌟 主要功能

### 1. 战绩录入与管理
*   **多赛制支持**：完整支持 **MD (Master Duel)** 与 **OCG** 两种模式，数据相互独立。
*   **精细化记录**：
    *   记录胜负结果、日期（支持 1~31 号及月历选择）、备注。
    *   **OCG 专有**：支持录入三局两胜（Matches）的具体小局结果。
    *   **进阶指标**：记录起手动点、手坑、废件数量（0~7 范围）。
    *   **失败原因**：支持从历史记录中选择或自定义输入失败原因（单场最多 3 项），帮助复盘。
*   **卡组图片**：每个卡组支持上传最多 3 张构筑图，支持本地预览、删除及保存至相册。

### 2. 统计分析
*   **基础统计**：总场次、胜率、胜负波动趋势。
*   **骰子统计**：赢骰率以及赢/输骰后的对应胜率，直观展现“运气”对战绩的影响。
*   **连胜/连败提醒**：自动计算当前筛选范围内的最新连胜或连败局数（3局起显示）。
*   **可视化饼图**：
    *   **对手卡组分布**：自动生成对手卡组占比饼图。
    *   **自定义配色**：支持对饼图扇区进行自定义换色，颜色按排序位置保存。
    *   **多维筛选**：可按月份、对战类型、卡组、MD 账号等维度进行复合筛选。

### 3. 数据储存与迁移
*   **纯本地存储**：数据仅保存在手机本地，不依赖服务器。
*   **全量备份**：支持导出全量 JSON 备份文件，方便在更换设备时覆盖恢复。
*   **CSV 导出/导入**：
    *   支持将筛选后的战绩导出为 CSV 表格，便于在 Excel 中二次分析。
    *   支持从 CSV 文件合并导入战绩，具备精确去重功能。
*   **小程序迁移**：支持从微信小程序版导出专用 JSON 并在此 App 中无缝导入。

## 🛠️ 技术栈
*   **框架**：uni-app (Vue 3 + Vite)
*   **存储**：本地文件系统 + JSON 数据库
*   **校验**：内置 Node.js 冒烟测试脚本 (58 项用例) 确保核心逻辑稳定。

## 📂 项目结构
*   `pages/index/index.vue`：主页面，包含统计、列表、设置三大模块。
*   `services/`：核心业务逻辑层（数据库操作、API 仿真、备份处理）。
*   `tools/`：开发辅助工具（代码校验、冒烟测试）。
